# FileSweeper

A tiny Python script that automatically organizes messy folders (Downloads, Desktop, etc.) into neat subfolders like Images, Documents, Videos, Archives, and Code.

## The Problem

Your Downloads folder is a disaster. You can't find anything. You keep scrolling through hundreds of files.

## The Solution

One command, and everything gets sorted.

## 🚀 Usage

```bash
# DRY RUN (safe - just shows what it will do)
python filesweeper.py ~/Downloads

# ACTUALLY ORGANIZE (moves files)
python filesweeper.py ~/Downloads --execute
